# Security Policy

## Supported versions

Security fixes are made against the latest version on the default branch. There are no separately maintained release branches.

## Report a vulnerability

Please do not report vulnerabilities in a public issue. Email [guuleedmaxamuud40@gmail.com](mailto:guuleedmaxamuud40@gmail.com) with a description, affected route or file, steps to reproduce, and any potential impact. Avoid including real personal data, credentials, or secrets in a report.

The maintainer will review the report and follow up by email. Please allow a reasonable opportunity to investigate and address a confirmed issue before sharing technical details publicly. Do not access or modify data that is not yours, disrupt the live service, or perform testing that could affect other users.

## Scope

This policy covers this repository and the application at [guuleedmaxamuud.dev](https://www.guuleedmaxamuud.dev/). Third-party services and dependencies are outside the maintainer's control; reports about them should also go to their respective maintainers.
